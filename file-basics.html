ファイルに名前を付けて保存・コピー・移動する

Windows版のWord・Excel・PowerPointは、ファイルの保存の流れがだいたい一緒です。レポートでも発表スライドでも、私なら最初に「参照」からOneDriveの授業フォルダーを開いて、そこで名前を付けて保存します。

「参照」から保存する

  1. 左上の「ファイル」から「名前を付けて保存」を選びます。すでにOneDriveに入っているファイルでは「コピーの保存」と表示されることがあります。
  2. 「参照」を押します。ファイルの保存先を選ぶ画面が開きます。
  3. 左側の一覧から大学のOneDriveを開いて、前に作った授業フォルダーまで進みます。たとえば、OneDrive → 1年春 → 月1_教育原理 です。
  4. そのフォルダーを開いた状態で「ファイル名」欄に名前を入れて、「保存」を押せばOKです。

課題なら、ファイル名は先生の指定に合わせてください。「学籍番号＋名前」が同じでも、授業ごとのフォルダーに入れてあれば、あとでどの授業の課題か分かります。

「参照」の一覧に大学のOneDriveが出てこなければ、アプリの保存先一覧で大学アカウントのOneDriveを選べるか確認してください。

元のファイルを残したいならコピー

配布されたひな形を使うときは、編集する前に「名前を付けて保存」か「コピーの保存」で、自分用の名前を付けて保存します。エクスプローラーからコピーするなら、ファイルを選んで Ctrl＋C、保存先を開いて Ctrl＋V です。

置き場所だけ変えたいなら移動

違うフォルダーに保存しちゃったときは、作業中のファイルを保存して閉じます。エクスプローラーでファイルを選んで Ctrl＋X、正しい授業フォルダーを開いて Ctrl＋V。移動先にファイルが入ったことを確認してください。
