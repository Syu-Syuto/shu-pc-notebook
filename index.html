    • Word・Excel・PowerPointは何に使う？
    • 大学のメールを確認する

    その他

    • 入れておくと便利なアプリ・サービス一覧
    • Windows Updateと再起動の時間を設定する
    • タスクバーのアイコンを左に寄せる
    • 画面が消える時間・スリープまでの時間を変える
    • 大学生活で使う生成AIはどれがいい？

    ファイルの基本

    • ダウンロードしたファイルを見つける
    • ファイルに名前を付けて保存・コピー・移動する
    • PDF・Word・ZIPの違いを知る
    • Windows・Chrome・Officeのショートカットまとめ
    • USB-Cで何ができる？ 充電・転送・映像出力

    授業・空き時間

    • 授業のお知らせと配布資料を見つける
    • 大学で印刷するには？ コンビニと生協のプリンター
    • 配布資料をOneDriveの授業別フォルダーに保存する
    • オンライン授業に参加する
    • マイクやカメラが使えないときに確認する
    • スクリーンショットを撮って保存する
    • 空き教室検索ツールで自習場所を探す
    • OneNoteで授業ノートを取る
    • シラバスの見方

    レポート・発表

    • Wordでレポートを作り、体裁を整える
    • Wordの文書をPDFにして確認する
    • PowerPointで発表スライドを作る
    • Excelで表を作ってグラフにする

    提出・共有

    • 課題の締切・ファイル形式・ファイル名を確認する
    • 課題を提出して、出せたか確認する
    • グループで同じファイルを共同編集する

    困ったとき

    • 大学アカウントにログインできない
    • OneDriveのファイルが同期されない
    • 上書き・削除したOneDriveのファイルを復元する
    • Caps Lockで英字が大文字になるとき
    • ファンクションキーとFnキーの使い方

    トラブルシューティング

    いま困っているとき

    • 起動時にBitLockerの回復キーを聞かれた
    • 電源ボタンを押しても反応しない
    • 電源は入るのに画面が真っ暗
    • Windowsのロゴや「自動修復」から先に進まない
    • Windows Updateのあとから調子が悪い
    • PINが使えなくてWindowsに入れない
    • Wi-Fiにつながらない・つながってもネットが使えない
    • 教室のプロジェクターに画面が映らない
    • USBメモリや外付けSSDが認識されない
    • USB-Cを挿しても充電されない
    • Cドライブがいっぱいで保存や更新ができない

    PCが動くうちに備える

    • Windowsが起動しなくなる前に回復用USBを作る
